# データ更新の手順

Wikipedia（勝ち馬）と Wikidata（父・生年）から取得し、確認してから `data/` に反映します。
GitHub Codespaces で作業することを想定しています（必要なパッケージは自動でインストールされます）。

## 1. 取得

```sh
# 勝ち馬（例：2005 年以降）→ staging/winners_raw.csv
python -m pedigree fetch winners --from 2005

# 父・生年 → staging/horses_raw.csv
#   未登録の勝ち馬は、既存の馬につながるまで父をさかのぼって取得します
#   既存の馬の生年も取得します（不要なら --no-existing）
python -m pedigree fetch horses
```

- 応答は `.cache/http/` に保存されるので、途中で止まっても再実行すれば続きから取得します。
- アクセス過多（HTTP 429）の場合は自動で待って再試行します。間隔は `--interval`（秒）で変えられます。

## 2. 照合

```sh
python -m pedigree review   # → staging/review.csv
```

`review.csv` の各行は次のとおりです。

| Kind | 内容 |
|---|---|
| `horse` | 新しく登録する馬（父・生年つき） |
| `birth_year` | 既存の馬に生年を追加 |
| `win` | 新しく登録する勝利 |
| `check` | 参考情報（既存データとの食い違い）。反映はされません |

- 問題のない行は `Approve` が `y` になっています。
- `Note` に理由が書かれた行は `Approve` が空欄です。内容を確認し、正しければ `y` を入れてください。
  馬名や父を直して承認することもできます。
- 反映したくない行は `Approve` を空欄にしてください。

### 確認画面

```sh
python -m pedigree admin
```

ブラウザで確認画面が開きます（Codespaces ではポート 8501 の転送先を開いてください）。

- **確認**タブ：一覧を種別・要確認・未承認・キーワードで絞り込み、承認・馬名・父・生年を直接修正できます。
  「出典」のリンクから Wikidata・Wikipedia の元情報を確認できます。
  「保存」で review.csv に書き戻し、「検証して data/ に反映」で反映します。
  不要な行は「外す」にチェックし、「『外す』にチェックした行を一覧から外す」で確認一覧から外せます。
- **手動追加**タブ：取得できなかった馬（父系の途中の外国産馬など）や勝利を追加します。
  確認一覧や data/ にすでにある馬・勝利は二重に追加しません（確認一覧の行は更新・承認し、
  data/ に登録済みの馬は生年が入力されていれば生年の行だけを追加します）。
- **データ**タブ：現在のデータの件数と検証結果を表示します。

反映した行は review.csv から外れ、未承認の行だけが残ります。

### 生年が空欄の馬

```sh
python -m pedigree births   # 年齢限定戦からの計算と Wikipedia の情報欄で分かる分を review.csv に追加
```

残った馬は確認画面の「生年の入力」タブで入力します。

- **まとめて貼り付け**：1 行に 1 頭、「馬名 生年」の形で貼り付けると、対応する馬と目安の範囲をプレビューしてから追加できます。
  カナ・英字のどちらの表記でも探します（取得時に保存した別表記を使います）。
- **一覧から入力**：同じ父系の馬が続けて並ぶので、系統で絞り込んで父系をたどりながら入力できます。
  「目安」は父の生年＋3 年から、子の生年－3 年・初勝利－2 年までの範囲です。

### 同名の馬

- 承認した馬には Wikidata の Q 番号が記録され、次回からは名前ではなく Q 番号で照合します。
- 取得した馬が既存の馬と同名でも、Q 番号や父が食い違う場合は**別の馬**として扱います。
  新規登録が必要な場合は `Pharamond (1925)` のように馬名に生年を付けた行が作られます（要確認）。
- 既存の馬を名前で探したときに父が合わない場合は、同名の別の馬を検索して父が合うものを使います。

## 3. 反映（コマンドで行う場合）

```sh
python -m pedigree apply --dry-run   # 確認だけ
python -m pedigree apply             # data/ に反映
python -m pedigree validate
```

反映後のデータが検証に通らない場合は中止し、`data/` は変更しません。

## 1 件だけ追加する場合

```sh
python -m pedigree add horse 新しい馬 --father 父の馬名 --birth 2023
python -m pedigree add win 2026 有馬記念 新しい馬
```

## 4. コミットと公開

```sh
git checkout -b data-2026-autumn
git add data/
git commit -m "2026 年秋の G1 勝ち馬を追加"
git push -u origin data-2026-autumn
```

GitHub で PR を作ると CI がデータを検証します。`main` にマージすると、GitHub Actions（Pages）が
階層図を作り直して公開ページに反映します（数分かかります）。
